How to read this report

Missing cells and exact duplicate records are flagged without a schema. Optional schema rules add required, finite-number, inclusive range and exact allowed-category checks. Rules do not infer business meaning.

Duplicate records compare all raw cells; distinct values are also exact. Numeric checks permit surrounding whitespace and scientific notation. Allowed categories are case-sensitive and untrimmed.

Use your browser's Print command to save this report as PDF. Expand this explanation first if you want it included. Column headers remain visible, so review them before sharing.
